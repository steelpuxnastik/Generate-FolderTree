# Generate-FolderTree.ps1

Создано с помощью клауда, полезная для меня утилитка :)

PowerShell-скрипт для Windows: сканирует папку и создаёт HTML-дерево файлов с поиском, размерами, датами и (опционально) хэшами. Поддерживает **инкрементальное обновление** — при повторном скане помнит историю: новые файлы помечает NEW, пропавшие не удаляет, а помечает GONE, изменённые — CHANGED. Плюс редактирование прямо в браузере: свои заметки, виртуальные папки, удаление ненужных записей.

---

## 1. Что нужно для запуска

- Windows 10/11 (или Windows 7+) со встроенным PowerShell — ничего дополнительно устанавливать не нужно. 
- Сам файл `Generate-FolderTree.ps1`. **Обязательно в кодировке UTF-8 with BOM** (Notepad++: Encoding → UTF-8-BOM), иначе кириллица превращается в кракозябры.

## 2. Файлы проекта

- `Generate-FolderTree.ps1` — сам скрипт. 
- `ИмяОтчёта.html` — тонкая оболочка-интерфейс, сама по себе почти не весит (десятки КБ). Открывается двойным кликом в браузере.
- `ИмяОтчёта.data.js` — **все данные хранятся здесь**. Может быть большим на объёмных папках и в зависимости от параметров сканирования.
- `ИмяОтчёта.data.js.bak` — резервная копия `.data.js` на один шаг назад. Создаётся автоматически перед каждой перезаписью (`-Update`, `-DeletePattern`, `-AddNote`, `-RestoreAll`, `-RestorePattern`). Хранится только последняя версия, не архив за всё время. Восстановление вручную: удалить испорченный `.data.js`, переименовать `.data.js.bak` → `.data.js`.

HTML и `.data.js` всегда должны лежать рядом и с одинаковым именем (без расширения) — HTML подгружает данные из `.data.js` при открытии.

**Защита от зацикливания:** символьные ссылки и junction-точки пропускаются при сканировании — скрипт не уйдёт в бесконечный цикл на таких ссылках (они нередко встречаются в системных папках Windows).

## 3. Как запустить — пошагово

### Шаг 1. Откройте PowerShell

Есть два инструмента, которые часто путают:

- **Командная строка (cmd.exe)** — старая чёрная консоль Windows.
- **PowerShell** — более новая консоль, именно её понимает скрипт.
Можно использовать и то, и другое, но в случае первого нужно правильно обращаться к PowerShell через командную строку. Для меня через командную строку работает обращение:
```cmd
powershell -ExecutionPolicy Bypass *и дальше аргументы*
```
но лучше использовать PowerShell напрямую, о чем дальше и речь.

Скрипт `.ps1` — файл PowerShell. Запускать напрямую двойным кликом обычно не получится (Windows по умолчанию открывает `.ps1` в блокноте или блокирует запуск) — поэтому запускаем через консоль.

**Как открыть PowerShell:**
- `Win + X` → выберите "PowerShell"
- Либо `Win + R` → введите `powershell` → Enter.
- Либо зажмите `Shift` и кликните правой кнопкой мыши на папке в проводнике → "Открыть окно PowerShell здесь".

### Шаг 2. Перейдите в папку со скриптом (если открываете PowerShell не из папки со скриптом напрямую)

```powershell
cd "D:\Dokumenty\Место_где_вы_сохранили_скрипт"
```

Кавычки обязательны, если в пути есть пробелы.

### Шаг 3. Запустите скрипт

Из-за политики безопасности Windows запуск `.ps1`-скриптов обычно заблокирован по умолчанию. Самый простой способ обойти это (не меняет системных настроек, действует только на этот запуск):

```powershell
powershell -ExecutionPolicy Bypass -File "Generate-FolderTree.ps1" -Path "D:\ПутьКСканируемойПапке"
```

Если политика выполнения уже разрешена (см. раздел 8), можно короче:

```powershell
.\Generate-FolderTree.ps1 -Path "D:\ПутьКСканируемойПапке"
```

### Шаг 4. Откройте результат

По умолчанию — `FolderTree.html` рядом со скриптом. Откройте его двойным кликом — откроется в браузере.

## 4. Все параметры

| Параметр | Описание |
|---|---|
| `-Path` | Папка для сканирования. По умолчанию — текущая |
| `-OutputFile` | Путь к HTML. По умолчанию — `FolderTree.html` рядом со скриптом |
| `-MaxDepth` | Глубина вложенности. `0` = без ограничений |
| `-IncludeHash` | Считать хэш каждого файла (медленно на больших объёмах) |
| `-HashAlgorithm` | `MD5`/`SHA1`/`SHA256`/`SHA384`/`SHA512`. По умолчанию `SHA256` |
| `-HashSizeLimitMB` | Не хэшировать файлы крупнее N МБ. По умолчанию `200` |
| `-Update` | Пересканировать по уже сохранённому пути, объединив с историей |
| `-DeletePattern` | Исключить записи по маске (`-like`), например `"*.tmp"` |
| `-AddNote` | Добавить заметку: `"путь\к\файлу|текст"` или `"текст"` (общая) |
| `-RestoreAll` | Вернуть все исключённые записи обратно |
| `-RestorePattern` | Вернуть исключённые записи по маске |
| `-Status` | Показать сводку по отчёту в консоли, ничего не меняя |

### `-Path` / `-OutputFile`

```powershell
.\Generate-FolderTree.ps1 -Path "D:\Projects"
.\Generate-FolderTree.ps1 -Path "."                                 # текущая папка
.\Generate-FolderTree.ps1 -Path "D:\Backup" -OutputFile "D:\Отчёты\backup.html"
.\Generate-FolderTree.ps1                                           # без параметров — текущая папка, FolderTree.html рядом
```

### `-MaxDepth`

- `0` (по умолчанию) — без ограничений, обходит всё до самого дна.
- `1` — только содержимое корневой папки, без захода в подпапки.
- `2`, `3`... — соответствующее число уровней вложенности.

Полезно для очень больших/глубоких деревьев (весь диск), чтобы сканирование не заняло слишком много времени.

```powershell
.\Generate-FolderTree.ps1 -Path "D:\" -MaxDepth 2
```

### `-IncludeHash`, `-HashAlgorithm`, `-HashSizeLimitMB`

Работают вместе. `-IncludeHash` — флаг, без значения. Хэширование требует прочитать каждый файл целиком — на больших объёмах это ощутимо замедляет работу (вместо минут может быть часы). Используйте, только если хэши реально нужны (сравнение файлов, проверка целостности после копирования).

```powershell
# SHA256, лимит 200 МБ по умолчанию
.\Generate-FolderTree.ps1 -Path "D:\Docs" -IncludeHash

# MD5 быстрее — разумный выбор, если хэш нужен просто для сравнения
# файлов между собой, а не для криптостойкости
.\Generate-FolderTree.ps1 -Path "D:\Docs" -IncludeHash -HashAlgorithm MD5

# Убрать лимит вообще (может быть ОЧЕНЬ долго на образах дисков)
.\Generate-FolderTree.ps1 -Path "D:\Backup" -IncludeHash -HashSizeLimitMB 0
```

### `-Update`, `-DeletePattern`, `-AddNote`, `-RestoreAll`, `-RestorePattern`, `-Status`

```powershell
# Первое сканирование
.\Generate-FolderTree.ps1 -Path "D:\Backup" -OutputFile "D:\Отчёты\backup.html"

# Повторное сканирование — путь запоминается автоматически,
# обновит New/Gone/Changed, ничего не забывает
.\Generate-FolderTree.ps1 -Update -OutputFile "D:\Отчёты\backup.html"

# Исключить все .tmp файлы из отчёта
.\Generate-FolderTree.ps1 -DeletePattern "*.tmp" -OutputFile "D:\Отчёты\backup.html"

# Вернуть исключённые файлы обратно
.\Generate-FolderTree.ps1 -RestorePattern "*.tmp" -OutputFile "D:\Отчёты\backup.html"

# Добавить заметку к конкретному файлу
.\Generate-FolderTree.ps1 -AddNote "Games\save.zip|актуальный бэкап сохранений" -OutputFile "D:\Отчёты\backup.html"

# Посмотреть сводку без пересканирования
.\Generate-FolderTree.ps1 -Status -OutputFile "D:\Отчёты\backup.html"
```

## 5. Примеры на разные случаи

**Быстрый обзор всего диска без ухода в глубину:**
```powershell
.\Generate-FolderTree.ps1 -Path "D:\" -MaxDepth 2 -OutputFile "D:\Отчёты\диск-D-обзор.html"
```

**Полная инвентаризация бэкапа с хэшами (найти дубликаты):**
```powershell
.\Generate-FolderTree.ps1 -Path "D:\Backup" -IncludeHash -HashAlgorithm MD5 -HashSizeLimitMB 500 -OutputFile "D:\Отчёты\backup-hashes.html"
```

**Сетевая папка, где важна скорость:**
```powershell
.\Generate-FolderTree.ps1 -Path "\\NAS\Shared\Archive" -MaxDepth 3
```

**Сохранить результат на рабочий стол:**
```powershell
.\Generate-FolderTree.ps1 -Path "D:\Projects" -OutputFile "$env:USERPROFILE\Desktop\projects-tree.html"
```

## 6. Что показывает результат (HTML)

- **Дерево** — клик по папке сворачивает/разворачивает содержимое.
- **Поиск** — печатаете в поле, дерево фильтруется в реальном времени, совпадения подсвечиваются, нужные ветки разворачиваются.
- **Размер** — у файлов свой, у папок — суммарный по содержимому.
- **Даты, хэш** (если включён `-IncludeHash`).
- **Цветовая подсветка "тяжёлых" элементов** — полоска слева: 
  жёлтая (средний размер) → оранжевая (крупный) → красная (очень крупный).
- **New / Changed / Gone** — при повторном скане новые файлы, изменённые и пропавшие подсвечиваются и фильтруются кнопками.
- **История обновлений** — список всех прошлых пересканирований.

## 7. Что можно делать прямо в браузере

- **Фильтр по статусу** — кнопки New/Changed/Gone вверху, если такие есть.
- **+ Строка / + Папка** — добавить свою заметку или виртуальную папку в любое место дерева (не влияет на реальные файлы на диске).
- **Чекбоксы → Удалить выбранные** — включите чекбоксы (галочка "Чекбоксы" в панели), отметьте ненужные записи, нажмите "Удалить выбранные". Не трогает файлы на диске, только отчёт.
- **💾 Сохранить** — браузер не может писать файлы на диск напрямую (ограничение безопасности), поэтому кнопка **скачивает** новый `.data.js` в "Загрузки". Замените им старый `.data.js` рядом с HTML и перезагрузите страницу (F5), чтобы увидеть изменения.
- **🔄 Rescan and update** — готовая команда для пересканирования показана внизу страницы. Клик по ней копирует её в буфер обмена — вставьте в PowerShell.

## 8. Разрешить запуск скриптов насовсем (необязательно)

Если не хотите каждый раз писать `-ExecutionPolicy Bypass`, можно один раз разрешить запуск локальных скриптов для своего пользователя (прав администратора не требует):

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

После этого свои/скачанные и открытые скрипты запускаются без дополнительных флагов: `.\Generate-FolderTree.ps1 -Path "D:\Projects"`.

`RemoteSigned` — безопасный вариант: локальные скрипты работают свободно, а скачанные из интернета потребуют цифровой подписи.

## 9. Частые проблемы

**"Выполнение сценариев отключено в этой системе"**
См. раздел 3, шаг 3 (`-ExecutionPolicy Bypass`) или раздел 8 (разрешить насовсем).

**Кракозябры вместо кириллицы (например, "Р“Р‘" вместо "ГБ")**
Файл `.ps1` сохранён не в UTF-8 with BOM. Пересохраните в BOM (Notepad++: Encoding → Convert to UTF-8-BOM).

**Скрипт зависает или работает очень долго**
Скорее всего включён `-IncludeHash` на большом объёме данных — это ожидаемо. Либо слишком большая глубина на очень объёмной папке — ограничьте `-MaxDepth` для первого пробного запуска.

**Некоторые папки помечены "⚠️ Нет доступа"**
Системные/защищённые папки Windows. Запустите PowerShell от имени администратора, если нужно просканировать и их тоже.

**Дерево не отображается / пустая область**
Проверьте, что `.data.js` лежит рядом с HTML и не был случайно удалён/переименован.

**`-Update` не находит перемещённый файл**
Работает только внутри изначально указанной корневой папки (`-Path` при первом запуске). Файлы, перемещённые за её пределы, не отслеживаются.
