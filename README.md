# Generate-FolderTree.ps1

Создано с помощью клауда, полезная для меня утилитка :)

PowerShell-скрипт для Windows: сканирует папку и создаёт HTML-дерево
файлов с поиском, размерами, датами и (опционально) хэшами.
Поддерживает **инкрементальное обновление** — при повторном скане
помнит историю: новые файлы помечает NEW, пропавшие не удаляет, а
помечает GONE, изменённые — CHANGED. Плюс редактирование прямо в
браузере: свои заметки, виртуальные папки, удаление ненужных записей.

## 1. Файлы проекта

- `Generate-FolderTree.ps1` — сам скрипт. **Обязательно сохранять в
  кодировке UTF-8 with BOM** (Notepad++: Encoding → UTF-8-BOM), иначе
  кириллический текст превращается в кракозябры.
- `ИмяОтчёта.html` — тонкая оболочка-интерфейс, сам по себе почти не
  весит (десятки КБ). Открывается двойным кликом в браузере.
- `ИмяОтчёта.data.js` — **все данные хранятся здесь**. Может быть
  большим на объёмных папках — это нормально.

HTML и `.data.js` всегда должны лежать рядом и с одинаковым именем
(без расширения) — HTML подгружает данные из `.data.js` при открытии.

## 2. Как запустить

```powershell
powershell -ExecutionPolicy Bypass -File "Generate-FolderTree.ps1" -Path "D:\Папка"
```

Если разрешён запуск скриптов (`Set-ExecutionPolicy -Scope CurrentUser
-ExecutionPolicy RemoteSigned`), можно короче: `.\Generate-FolderTree.ps1 -Path "D:\Папка"`.

Результат — `FolderTree.html` рядом со скриптом (если не указан `-OutputFile`).
Откройте HTML в браузере — Windows создаст ярлык на командную строку не нужен.

## 3. Параметры

| Параметр | Описание |
|---|---|
| `-Path` | Папка для сканирования. По умолчанию — текущая |
| `-OutputFile` | Путь к HTML. По умолчанию — `FolderTree.html` |
| `-MaxDepth` | Глубина вложенности. `0` = без ограничений |
| `-IncludeHash` | Считать хэш каждого файла (медленно на больших объёмах) |
| `-HashAlgorithm` | `MD5`/`SHA1`/`SHA256`/`SHA384`/`SHA512`. По умолчанию `SHA256` |
| `-HashSizeLimitMB` | Не хэшировать файлы крупнее N МБ. По умолчанию `200` |
| `-Update` | Пересканировать по уже сохранённому пути, объединив с историей |
| `-DeletePattern` | Исключить записи по маске (`-like`), например `"*.tmp"` |
| `-AddNote` | Добавить заметку: `"путь\к\файлу|текст"` или просто `"текст"` (общая) |
| `-RestoreAll` | Вернуть все исключённые записи обратно |
| `-RestorePattern` | Вернуть исключённые записи по маске |
| `-Status` | Показать сводку по отчёту в консоли, ничего не меняя |

## 4. Примеры

```powershell
# Первое сканирование
.\Generate-FolderTree.ps1 -Path "D:\Backup" -OutputFile "D:\Отчёты\backup.html"

# Повторное сканирование (тот же путь, что и при первом запуске,
# запоминается автоматически) — обновит New/Gone/Changed
.\Generate-FolderTree.ps1 -Update -OutputFile "D:\Отчёты\backup.html"

# Исключить все .tmp файлы из отчёта
.\Generate-FolderTree.ps1 -DeletePattern "*.tmp" -OutputFile "D:\Отчёты\backup.html"

# Добавить заметку к конкретному файлу
.\Generate-FolderTree.ps1 -AddNote "Games\save.zip|актуальный бэкап сохранений" -OutputFile "D:\Отчёты\backup.html"

# Посмотреть сводку без пересканирования
.\Generate-FolderTree.ps1 -Status -OutputFile "D:\Отчёты\backup.html"
```

## 5. Что можно делать прямо в браузере

- **Поиск, разворачивание/сворачивание** — как обычно.
- **Фильтр по статусу** — кнопки New/Changed/Gone вверху, если такие есть.
- **+ Строка / + Папка** — добавить свою заметку или виртуальную папку
  в любое место дерева (не влияет на реальные файлы на диске).
- **Чекбоксы → Удалить выбранные** — включите чекбоксы (галочка
  "Чекбоксы" в панели), отметьте ненужные записи, нажмите "Удалить
  выбранные". Это не трогает файлы на диске, только отчёт.
- **💾 Сохранить** — браузер не может писать файлы на диск напрямую
  (ограничение безопасности), поэтому кнопка **скачивает** новый
  `.data.js` в папку "Загрузки". Нужно вручную заменить им старый
  `.data.js` рядом с HTML — после этого браузер надо перезагрузить
  (F5), чтобы увидеть изменения. Это единственный неудобный шаг во
  всём процессе.
- **🔄 Rescan and update** — команда для пересканирования уже готова
  и показана внизу страницы. Кликните по ней, чтобы скопировать в
  буфер обмена, и вставьте в PowerShell.

## 6. Частые проблемы

**Кракозябры вместо кириллицы** — файл `.ps1` сохранён не в
UTF-8 with BOM. Пересохраните в BOM (Notepad++: Encoding → Convert to
UTF-8-BOM).

**Дерево не отображается / пустая область** — проверьте, что
`.data.js` лежит рядом с HTML и не был случайно удалён/переименован.

**"Выполнение сценариев отключено"** — см. раздел 2, добавьте
`-ExecutionPolicy Bypass` или разрешите через `Set-ExecutionPolicy`.

**HTML раздутый (сотни МБ)** — актуальная версия хранит данные
только в `.data.js`, HTML — тонкая оболочка. Если HTML всё равно
большой — используется старая версия скрипта, замените на актуальную.

**`-Update` не находит перемещённый файл** — работает только внутри
изначально указанной корневой папки (`-Path` при первом запуске).
Файлы, перемещённые за её пределы, не отслеживаются.
