# Generate-FolderTree.ps1

Создано с помощью клауда, полезная для меня утилитка :)

PowerShell-скрипт для Windows, который сканирует папку и создаёт красивый
самостоятельный HTML-файл с иерархией всех файлов и подпапок. Дерево можно
сворачивать/разворачивать, искать по имени, видеть размеры, даты и (по
желанию) хэши файлов. "Тяжёлые" файлы и папки подсвечиваются цветом.

Результат — один HTML-файл без внешних зависимостей. Его можно открыть
в любом браузере на любом компьютере, интернет не нужен.

---

## 1. Что нужно для запуска

- Windows 10/11 (или Windows 7+) со встроенным PowerShell — ничего
  дополнительно устанавливать не нужно.
- Сам файл `Generate-FolderTree.ps1`.

---

## 2. Как запустить — пошагово

### Шаг 1. Откройте PowerShell или командную строку

Есть два инструмента, которые часто путают:

- **Командная строка (cmd.exe)** — старая чёрная консоль Windows.
- **PowerShell** — более новая консоль, именно её понимает наш скрипт.

Скрипт `.ps1` — это файл PowerShell. Запускать напрямую двойным кликом
обычно не получится (Windows по умолчанию открывает `.ps1` в блокноте
или блокирует запуск) — поэтому запускаем через консоль.

**Как открыть PowerShell:**
- Нажмите `Win + X` → выберите "Windows PowerShell" или "Терминал".
- Либо: `Win + R` → введите `powershell` → Enter.
- Либо: зажмите `Shift` и кликните правой кнопкой мыши на папке в
  проводнике → "Открыть окно PowerShell здесь" (или "Открыть в терминале").

### Шаг 2. Перейдите в папку со скриптом

Если PowerShell открылся не в той папке, где лежит скрипт, перейдите
командой `cd` (change directory):

```powershell
cd "D:\diskD\Скрипт создания дерева файлов в папке"
```

Кавычки обязательны, если в пути есть пробелы (как в этом примере).

### Шаг 3. Запустите скрипт

Из-за политики безопасности Windows запуск `.ps1`-скриптов обычно
заблокирован по умолчанию. Самый простой и безопасный способ обойти
это — запускать так (это не меняет никаких системных настроек,
действует только на этот один запуск):

```powershell
powershell -ExecutionPolicy Bypass -File "Generate-FolderTree.ps1" -Path "D:\ПутьКПапке"
```

Если политика выполнения у вас уже разрешена (см. раздел 6), можно
запускать короче:

```powershell
.\Generate-FolderTree.ps1 -Path "D:\ПутьКПапке"
```

### Шаг 4. Откройте результат

По умолчанию результат — файл `FolderTree.html` в той же папке, где
лежит скрипт. Просто откройте его двойным кликом — откроется в браузере.

## 3. Все параметры

| Параметр | Тип | Обязателен | По умолчанию | Описание |
|---|---|---|---|---|
| `-Path` | строка | нет | текущая папка | Какую папку сканировать |
| `-OutputFile` | строка | нет | `FolderTree.html` рядом со скриптом | Куда сохранить результат |
| `-MaxDepth` | число | нет | `0` (без ограничений) | Максимальная глубина вложенности папок |
| `-IncludeHash` | флаг (без значения) | нет | выключен | Считать ли хэш каждого файла |
| `-HashAlgorithm` | строка | нет | `SHA256` | Алгоритм хэширования: `MD5`, `SHA1`, `SHA256`, `SHA384`, `SHA512` |
| `-HashSizeLimitMB` | число | нет | `200` | Файлы крупнее этого размера (в МБ) не хэшируются. `0` = без ограничения |

### `-Path`

Папка, которую нужно просканировать. Можно указывать относительный
или полный путь.

```powershell
.\Generate-FolderTree.ps1 -Path "D:\Projects"
.\Generate-FolderTree.ps1 -Path "C:\Users\Иван\Documents"
.\Generate-FolderTree.ps1 -Path "."          # текущая папка
.\Generate-FolderTree.ps1 -Path "..\Другая папка"   # относительный путь
```

Если параметр не указан вообще — скрипт возьмёт папку, из которой
запущен PowerShell (текущую рабочую директорию).

```powershell
.\Generate-FolderTree.ps1
```

### `-OutputFile`

Путь и имя результирующего HTML-файла.

```powershell
.\Generate-FolderTree.ps1 -Path "D:\Projects" -OutputFile "C:\Temp\projects-tree.html"
.\Generate-FolderTree.ps1 -Path "D:\Backup" -OutputFile "D:\Отчёты\бэкап-24-08-2026.html"
```

Если не указан — по умолчанию создастся `FolderTree.html` рядом со
скриптом.

### `-MaxDepth`

Ограничивает, насколько глубоко скрипт будет спускаться по вложенным
папкам. Полезно для очень больших/глубоких деревьев (например, весь
диск), чтобы HTML не получился гигантским и генерация не заняла
слишком много времени.

- `0` (по умолчанию) — без ограничений, обходит всё до самого дна.
- `1` — покажет только содержимое корневой папки (без захода в
  подпапки — они будут показаны как "глубина ограничена").
- `2`, `3` и так далее — соответствующее число уровней вложенности.

```powershell
.\Generate-FolderTree.ps1 -Path "D:\" -MaxDepth 2
.\Generate-FolderTree.ps1 -Path "D:\Backup" -MaxDepth 4
```

### `-IncludeHash`, `-HashAlgorithm`, `-HashSizeLimitMB`

Эти три параметра работают вместе. `-IncludeHash` включает
хэширование (это флаг — просто добавляете его в команду, значение
указывать не нужно). Без него хэши не считаются вообще (по умолчанию).

**Важно:** хэширование требует прочитать каждый файл целиком, поэтому
на больших объёмах данных это ощутимо замедляет работу — вместо
секунд/минут генерация может занять часы. Используйте, только если
хэши реально нужны (например, для сравнения файлов или проверки
целостности после копирования).

```powershell
# Включить хэши с настройками по умолчанию (SHA256, лимит 200 МБ)
.\Generate-FolderTree.ps1 -Path "D:\Docs" -IncludeHash

# MD5 быстрее, чем SHA256 — разумный выбор, если хэш нужен просто
# чтобы сравнить файлы между собой, а не для криптостойкости
.\Generate-FolderTree.ps1 -Path "D:\Docs" -IncludeHash -HashAlgorithm MD5

# Поднять лимит размера файла для хэширования до 1000 МБ (1 ГБ)
.\Generate-FolderTree.ps1 -Path "D:\Backup" -IncludeHash -HashSizeLimitMB 1000

# Убрать лимит вообще (хэшировать все файлы, любого размера — 
# может быть ОЧЕНЬ долго на больших файлах типа образов дисков)
.\Generate-FolderTree.ps1 -Path "D:\Backup" -IncludeHash -HashSizeLimitMB 0
```

Файлы крупнее лимита в отчёте будут помечены как "хэш: файл больше
N МБ, пропущен" — сам файл при этом никуда не пропадает из дерева,
пропускается только вычисление хэша для него.

## 4. Примеры на разные случаи

**Просто посмотреть структуру папки с проектами:**
```powershell
.\Generate-FolderTree.ps1 -Path "D:\Projects"
```

**Быстрый обзор всего диска без ухода в глубину (чтобы не ждать
вечность и не получить гигантский файл):**
```powershell
.\Generate-FolderTree.ps1 -Path "D:\" -MaxDepth 2 -OutputFile "D:\Отчёты\диск-D-обзор.html"
```

**Полная инвентаризация бэкапа с хэшами для последующего сравнения
файлов (например, найти дубликаты между двумя бэкапами):**
```powershell
.\Generate-FolderTree.ps1 -Path "D:\IntelSSDBackup\BackupWin21072026" -IncludeHash -HashAlgorithm MD5 -HashSizeLimitMB 500 -OutputFile "D:\Отчёты\backup-21-07-hashes.html"
```

**Проверка большой сетевой/внешней папки, где важна скорость, без
хэшей и без лишней глубины:**
```powershell
.\Generate-FolderTree.ps1 -Path "\\NAS\Shared\Archive" -MaxDepth 3
```

**Сканирование текущей папки (просто зайти в нужную папку через
проводник, открыть там PowerShell и запустить без параметров):**
```powershell
.\Generate-FolderTree.ps1
```

**Сохранить результат прямо на рабочий стол:**
```powershell
.\Generate-FolderTree.ps1 -Path "D:\Projects" -OutputFile "$env:USERPROFILE\Desktop\projects-tree.html"
```

## 5. Что показывает результат (HTML)

- **Дерево папок и файлов** — клик по папке сворачивает/разворачивает
  её содержимое. Кнопки "Развернуть всё" / "Свернуть всё" вверху.
- **Поиск** — начинаете печатать в поле поиска, дерево фильтруется
  по совпадению с именем файла/папки в реальном времени, совпадения
  подсвечиваются, нужные ветки разворачиваются автоматически. Рядом
  показывается счётчик "Найдено: N".
- **Размер** — у файлов свой размер, у папок — суммарный размер всего
  содержимого (рекурсивно).
- **Даты** — дата последнего изменения и дата последнего доступа
  к файлу.
- **Хэш** — если был включён параметр `-IncludeHash`, показывается
  рядом с остальной информацией о файле.
- **Цветовая подсветка "тяжёлых" элементов** — полоска слева от
  файла/папки:
  - жёлтая — средний размер (файл от 10 МБ, папка от 100 МБ)
  - оранжевая — крупный (файл от 100 МБ, папка от 1 ГБ)
  - красная — очень крупный (файл от 1 ГБ, папка от 10 ГБ)
- **Шапка отчёта** — общее число файлов, папок, суммарный размер
  всей просканированной папки, дата генерации отчёта.

## 6. Разрешить запуск скриптов насовсем (необязательно)

Если вы часто пользуетесь PowerShell-скриптами и не хотите каждый раз
писать `-ExecutionPolicy Bypass`, можно один раз разрешить запуск
локальных скриптов для вашего пользователя (прав администратора
не требует):

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

После этого скрипты, которые вы написали или скачали и открыли сами
(не через интернет напрямую), будут запускаться без дополнительных
флагов:

```powershell
.\Generate-FolderTree.ps1 -Path "D:\Projects"
```

`RemoteSigned` — безопасный вариант: локальные/ваши скрипты работают
свободно, а скрипты, скачанные из интернета, потребуют цифровой
подписи (что и должно вас защищать от случайного запуска вредоносного
кода).

## 7. Частые проблемы

**"Выполнение сценариев отключено в этой системе"**
Политика выполнения PowerShell блокирует `.ps1`-файлы по умолчанию.
Решение — см. раздел 2, шаг 3 (`-ExecutionPolicy Bypass`) или раздел 6
(разрешить насовсем).

**Русский текст в консоли или в HTML выглядит как кракозябры
(например, "Р“Р‘" вместо "ГБ")**
Файл скрипта должен быть сохранён в кодировке UTF-8 с BOM — тогда
PowerShell 5.1 (встроенный в Windows) правильно его распознаёт. Файл,
который вы скачали, уже сохранён в этой кодировке. Если будете сами
редактировать скрипт в другом редакторе — убедитесь, что он сохраняет
именно "UTF-8 with BOM" (например, в Notepad++: Encoding →
UTF-8-BOM).

**Скрипт зависает или работает очень долго**
Скорее всего включён `-IncludeHash` на большом объёме данных — это
ожидаемо, хэширование требует чтения каждого файла целиком. Либо
слишком большая глубина (`-MaxDepth 0`) на очень объёмной папке —
попробуйте ограничить глубину для первого пробного запуска.

**"Не удается привязать аргумент к параметру Path"**
Возникало из-за пустого `$PSScriptRoot` при запуске через относительный
путь — в текущей версии скрипта это исправлено (есть запасной способ
определить папку скрипта).

**Некоторые папки помечены "⚠️ Нет доступа"**
Это системные/защищённые папки Windows, к которым у вашего
пользователя нет прав чтения. Запустите PowerShell от имени
администратора (правый клик → "Запуск от имени администратора"),
если нужно просканировать и их тоже.

## 8. Общая логика работы (кратко)

1. Скрипт рекурсивно обходит указанную папку через `Get-ChildItem`.
2. Для каждого файла считает размер, даты изменения/доступа и (по
   желанию) хэш.
3. Для каждой папки суммирует размер всего вложенного содержимого.
4. Строит HTML-дерево на основе нативных элементов `<details>` и
   `<summary>` — сворачивание/разворачивание работает без JavaScript,
   а JS используется только для поиска и кнопок "развернуть/свернуть
   всё".
5. Сохраняет всё в один самостоятельный HTML-файл, который не требует
   интернета и открывается в любом браузере.
